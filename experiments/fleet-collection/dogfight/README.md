# 舰队机动战斗实验

运行 `npm run dev`，从首页进入或访问 `/experiments/fleet-collection/dogfight/`。狗斗已确认为当前战斗方向；`battle/` 是保留的早期对射对照。使用相同舰体、固定武器、情报增长、冷却、ACC/EVA 命中及 PWR/DEF 伤害公式；舰船速度变为原来的三倍，AI 在目标距离过近时优先脱离，在合适距离侧向穿插，距离过远时接近，并尝试回避来袭弹道。目标距离是软约束，受其他舰船和速度影响，不保证永远保持最小间距。

双方每次攻击发射三发扇形弹幕，单发威力为原攻击的三分之一。弹道直线飞行至射程耗尽，并检测沿途所有敌方移动 hitbox；最先接触的敌方舰船触发原命中判定，弹丸随后消失。友军不受击，原目标退出后弹丸仍可击中其他敌人。因此机动回避是叠加在原命中概率之前的额外条件，不能直接把两个模式的胜率差异归因于 AI。弹道可以击中非原目标；其速度、碰撞半径、AI 和三倍移动速度是实验参数，并非平衡结论。步长为 0.1 秒，红蓝遵循同一规则。计数中的“未接触”表示射程耗尽且未接触任何敌方角色；尚不能等同于有效闪避次数。

建议使用相同种子与相同编队分别运行两个模式，观察交战距离、穿插、命中数量及持续时间；需要多种种子和试玩才能评估可行性。

战场没有固定边界，城市按角色与弹丸附近的区块生成和卸载。镜头以所有存活舰船的包围范围为目标，留出边距并平滑追踪、缩放；镜头仅影响显示，不影响战斗模拟。单位分散时会缩小以容纳所有单位，缩放和镜头位置有短暂的跟随延迟。

舰船转向限制角速度和角加速度，产生转向惯性；画面在模拟步之间插值，插值仅用于显示。当前参数为实验值，高速舰船会有更大的转弯半径。

## 2.5D 空间与地形

逻辑使用二维位置和离散的海面、空中、水下三层；垂直偏移仅用于表现。编队可选择航空与潜航实验单位，图标区分驱逐、巡洋、战列、航空和潜航。当前简化攻击规则：炮击可攻击海面与空中，鱼雷可攻击海面与水下，航空单位可攻击三层；情报仍按二维距离共享，并非完整航空或反潜模型。弹幕按发射时目标所在层碰撞该层的敌人。

普通楼宇不阻挡角色或弹幕；部分高楼阻挡海面和水下单位与所有层弹幕，低空飞行单位也会避开高楼。所有单位在武器冷却时尝试借助高楼接近并绕楼飞行，就绪后绕敌并寻找无遮挡射击路线，也在接近建筑时使用有限范围的局部网格寻路，碰撞约束阻止进入；受转向惯性和搜索范围影响，复杂地形旁仍可能停滞。地形布局、层间规则和数值均为原型假设。生成机制见 [CITY-GENERATION.md](CITY-GENERATION.md)。

战斗种子与地图种子旁的“随机”按钮会生成新的种子；也可以手动输入。更改后点击“应用并重置”才能用于下一场战斗。开放海面不使用地图种子。

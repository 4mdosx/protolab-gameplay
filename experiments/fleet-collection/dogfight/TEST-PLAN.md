# 下一阶段：角色表达与弹幕对照

## 目标

观察不同武器与 AI 配置能否让同属性角色表现出可辨认的战斗差异。先比较开放海面中的运动与弹幕，再检查城市高楼是否改变决策及可读性。

## 对照方法

1. 固定双方舰队和地图，复制一名角色配置：只改变武器的射程或 `spread`；用相同战斗种子分别试玩。
2. 固定角色属性与武器，复制 AI 模组：比较首选距离、环绕强度、闪避强度及是否使用掩体。其余参数保持一致。
3. 用同一编队和多个种子在开放海面与城市分别运行；记录观察到的行为、战斗时长、命中和未接触数。地图种子固定。
4. 检查角色是否被建筑卡住、是否绕楼接近、武器就绪后能否形成射击窗口；统计结果需要结合实际观看，不单凭胜率判断。

## 完成标准与限制

- 同一配置、地图和种子可复现；改变某个武器或 AI 参数应有可观察差异。
- 可以说出角色的差异来自弹幕、距离还是机动，而不只看伤害数值。
- 角色配置当前只支持编辑 TypeScript 文件；尚无页面编辑器、战斗参数快照导出或批量对比工具。
- 相同种子在不同配置下随机调用顺序可能不同，因此不是严格配对的随机实验；需要多个种子。
- 缺少大型场景性能基准、不同人格的正式策略和障碍附近卡住的完整处理。

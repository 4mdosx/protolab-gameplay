# 舰队单场战斗实验

分阶段计划与验证标准见 [PLAN.md](PLAN.md)。

此实验只模拟一次自动战斗：双方从固定初始位置开始，在二维场地中移动、积累敌方情报并使用绑定的武器攻击，直到一方全灭或超时。双方共用规则；固定种子可复现同一场战斗。入口：运行 `npm run dev`，访问 `/experiments/fleet-collection/battle/`。

当前实现是可观察的最小切片：七维属性、距离衰减的情报、发现和锁定阈值、接近 / 保持距离人格、固定主炮与鱼雷、冷却、命中与装甲伤害、战斗事件和超时。战场坐标及参数是实验单位。页面支持战前选择三艘蓝方舰船、单步、播放、重置与更改种子，动画不参与结算。

尚未实现：离线挂机、战区、收集、经济、养成、战术黑板协作、独立的投射物与拦截、复杂探测衰减、三维表现、完整角色编辑与平衡标定。当前情报为团队共享，未建模个体锁定容量；AI 仅有两种移动策略与最近目标选择。数值均为示例，不能用于判断正式平衡。

完整游戏设计、旧稿与待对账差异见 [设计索引](../../../ref/fleet-collection/docs/design-notes.md)。原始资料保留在 `../../../ref/fleet-collection/old/`。

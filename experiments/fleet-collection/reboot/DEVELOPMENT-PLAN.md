# 低空战斗平台开发计划

飞控优先级、积分顺序和调参入口见 [飞控与运动模型](./FLIGHT-MODEL.md)。

## 物理与能量

- 船头与速度分别积分。推进、制动和后坐改变当前速度，位置由运动与地形碰撞决定。舰种通过推重比、阻力和转向能力体现差异。
- 无有效推进输入时滑行并回能，仍受阻力影响。以巡洋 20 m/s、固定船头、无地形与后坐为基线，滑行 3 秒后顺滑约 13.0 m/s（47.7 m），横滑约 8.4 m/s（37.9 m）。
- 一档 10%、二档 35%，沿用常规回能规则。满推每秒消耗 18 点，主动制动每秒最多消耗 24 点，Step 一次消耗 32 点。锁定 BD 与普通满推共用扣能入口。

## 首轮操作

| 输入 | 行为 |
| --- | --- |
| 鼠标 | 自由驾驶时鼠标给出推力方向。 |
| Shift | 点按切换一、二档。 |
| 1/2、空格 | 选炮时固定最近的手动推力方向，鼠标改为瞄准。空格手动开火，未选炮时齐射。 |
| F | 预选或取消木桩。目标跟踪仅在锁定 BD 生效。 |
| 长按 Q | 无目标时临时满推。有目标时船头与炮塔跟踪，鼠标修正航向。BD 降低侧滑抑制，按当前速度与推力预算沿弧线转向。点击前跟随鼠标并预判约 2.2 秒的高楼碰撞，优先连续绕行，必要时增加侧推或制动。点击后优先保持航向快照，金色虚线在速度对准后淡出。松开即回到所选档位，继承速度和后坐。 |
| E | 按住制动，松开恢复推进。回正期间可以同时制动。 |
| 鼠标左键 | 点按时按鼠标位置和控制反向设置计算目标船头角，将结果记录为快照，并以侧推转到该角度。再次点左键 更新快照。无目标满推和 Step 可与回正并行，锁定 BD 清除快照。锁定 BD 中点左键 可退出目标跟踪并回正。 |
| W/A/S/D | 点按向屏幕上、左、下、右 Step。只在选定方向两侧 30° 内比较可行路线，优先选预计命中次数最少的一条。 |

推进优先级为 E 制动、Step、Q 满推、普通档位。成功触发 Step 或按住 E 会中断满推，必须松开再按才能重启。Step 能量不足或无变轨空间时保留当前机动，并分别显示原因。

## 输入绑定

`bindings.ts` 将物理按键和鼠标键映射到语义指令，并处理长按、松开、重复事件。`pilot-input.ts` 把指令转换成飞控已使用的持续状态和待消费请求。回正角度和预选目标由页面在触发时提供，动作优先级继续由飞控处理。默认键位来自绑定表，页面提示也读取这张表。

## 浮游炮弹幕

每门炮挂载独立的弹幕配置，并分别记录装填和波次。驱逐和巡洋的两门炮各发三波，每波一发，满装填齐射共六发。战列的主炮每波两发，副炮每波一发，各发三波，满装填齐射共九发。每一波按当时的实际炮口方向发射，计算弹道时叠加舰体速度。

## 验收场景

开启「木桩射击」，预选木桩后长按 Q 横掠，用空格开火。点按 W/A/S/D 接管推进，确认剩余能量和速度仍可继续使用。锁定 BD 时点左键改航向，确认追踪持续。退出 BD 后点左键回正，同时按住、松开 E，确认制动独立于回正。对比选炮状态下进入 BD、退出 BD 后的鼠标分工。

当前模拟保持 0.1 秒一拍。Step 预演复用运动积分和弹丸相对扫掠，按约 0.8 秒预测窗口比较候选路线。后续使用交叉弹幕与不同舰种检查规避时机、转弯半径和射击窗口。

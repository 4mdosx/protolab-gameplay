# 角色配置

- `characters.ts`：角色标识、舰种、空间层、基础属性、速度、装甲，以及武器和 AI 的引用。
- `weapons.ts`：武器射程、冷却、威力、弹速和弹幕角度（弧度）。一次攻击总威力均分到每发弹丸。
- `ai.ts`：首选距离、环绕和回避强度、是否利用掩体、角速度及角加速度。当前各模组复用同一个机动决策程序，不代表已实现独立战术 AI。
- `index.ts`：解析配置并校验角色引用和弹幕角度；战斗创建时生成独立副本。配置目前在代码中编辑，尚无网页配置编辑器、热保存或运行时外部文件导入。

数值用于实验，不代表最终平衡。更改配置后用固定种子和相同编队做对照；配置变更可能影响已有回放。

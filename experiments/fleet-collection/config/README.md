# 角色配置

- `historical-ships.ts`：历史舰身份；其 `configurations` 内记录时代/舰装配置、舰种、属性、速度、装甲和固定武器槽列表和一个预留功能装备槽。当前舰体均为虚构测试占位，并非历史资料。
- `characters.ts`：舰娘角色名、舰种、来源和 AI，引用历史舰与具体舰装配置。多个角色可引用同一历史舰。
- `weapons.ts`：武器射程、冷却、威力、弹速和弹幕角度（弧度）。一次攻击总威力均分到每发弹丸。
- `ai/`：独立策略模块。每个舰种声明多套策略，策略自带优先级状态树；角色挂其中一套，并用好战性、积极性缩放距离、脱离和闪避，得到同一棵树下的变种。状态树只选择战术。驱逐舰由转向层写成期望速度和期望朝向，`moveHull` 分开追踪；主炮有射界和齐射后坐。其他舰种仍把意图收成一个朝向，由 `moveSystem` 沿机体朝向前进。
- `index.ts`：按角色 → 历史舰 → 舰装配置解析数据，校验引用和弹幕角度；战斗创建时生成独立副本。配置目前在代码中编辑，尚无网页配置编辑器、热保存或运行时外部文件导入。

数值用于实验，不代表最终平衡。更改配置后用固定种子和相同编队做对照；配置变更可能影响已有回放。

## 主炮与鱼雷实验配方

`weapons.ts` 中型号有 `model`、`tier`、炮塔数 `mounts`、每座炮塔炮管数 `barrelsPerMount`、散布角和冷却；每次齐射的弹丸数量等于炮塔数乘炮管数。当前驱逐为 2×1、巡洋为 3×1、战列有 2×2 和 2×3 两个可选角色配置。型号、等级和数值是实验示例；等级本身不隐式改变属性，具体散布与冷却由型号参数明确指定。当前齐射从角色中心发射，尚未模拟独立炮塔位置或转向。

驱逐装备主炮及独立冷却的鱼雷，潜航单位装备鱼雷。鱼雷为黄色、较慢、散布更宽、冷却更长、伤害类型为水下且单次总威力更高；鱼雷目前是直线移动、不追踪、遇高楼阻挡，也不会命中空中单位。与主炮一样需要命中 hitbox 后再进行命中率判定；每轮总威力按弹丸数均分。不同武器独立选择目标并开火，当前 AI 的掩体和出击时机仍以主武器冷却为准；不代表完成了鱼雷预判或专门战术。

设计文档中的时代舰装配置目前嵌套在历史舰层，保留 `era` 和 `configurationYear` 可选字段；它不是单独的顶层数据表。未来需要跨舰引用或独立编辑时可再拆出。`sourceId: prototype` 仅标记实验来源，并不代表真实作品授权。

每个 `weaponSlots` 条目有独立 `slotId`、武器引用和战斗冷却；功能装备槽目前只有槽位标识，不实现装配或效果。候选清单见 [功能装备设计](EQUIPMENT-DESIGN.md)。当前 AI 仍以第一武器槽的冷却与射程安排进攻/掩体，其他武器各自自动开火。

目前驱逐、巡洋、战列、航母、潜航各有两名原创占位角色。同舰种的两名角色挂不同策略和参数，舰体配置除两种战列外仍然相同。

航母是可编队舰娘；舰载机属于航母衍生召唤单位，不是独立可收集角色。`carrierAirGroup` 通过 `summonId` 引用 `aircraft.ts`，舰载机拥有自己的 AI、属性和主炮配置。当前为原型规则：每次出动一架，每个飞机武器位的 `maxActive` 控制同时在场上限（当前默认三架）；舰载机有存续时间，航母退出后撤离。
